## 📖 Overview

**Wallet Wars** is a Web3 battle arena where blockchain history dictates combat destiny. Every Solana wallet has an innate personality shaped by its transaction history, balance, holding style, and protocol interactions.

Connect your Phantom, Solflare, or Backpack wallet (or enter any public address) to extract on-chain telemetry, synthesize a deterministic warrior, and engage in tactical arena battles against rival wallets.

> *"Compete. Earn. Conquer."*

---

## ⚡ Key Features

- 🔮 **Deterministic Warrior Synthesis**: Algorithmic generation engine evaluates SOL balance, wallet age, transaction frequency, token diversity, and DeFi footprint to construct unique stats, abilities, and personalities.
- 🥋 **10 Archetypes with Custom Abilities**: From the unstoppable `WHALE` with *Market Crash* to the chaotic `DEGEN` with *Chaos Strike* and the resilient `DIAMOND HANDS` with *Diamond Shield*.
- ⚔️ **Tactical Turn-Based Combat**: Real-time battle engine with initiative speed rolls, defense mitigation, elemental advantages, critical strikes, and procedural round logs.
- 🏆 **Global Leaderboard & ELO Rating**: Climb rankings across Win Rate, Total Battles, and Highest Win Streaks.
- 🎯 **Daily Challenges & Achievements**: Dynamic objectives rewarding strategic gameplay with unlocking trophy badges.
- 🌐 **Full Solana Wallet Adapter**: Seamless integration with Phantom, Solflare, Torus, Ledger, and demo sandbox mode for zero-barrier entry.
- ⚡ **Social Share & Battle Replays**: Share battle links with cinematic combat recaps for viral flexes on X / Twitter.

## 🚀 Quick Start

### 1. Prerequisites
- **Node.js** >= 18.0.0
- **npm** >= 9.0.0
- **MongoDB** (Local instance or free MongoDB Atlas cluster)
- Solana RPC URL (Optional: defaults to public mainnet/devnet endpoints)

### 2. Clone & Install

```bash
# Clone the repository
git clone https://github.com/Anurag12shukla/wallet-wars.git

# Enter project directory
cd wallet-wars

# Install all workspace dependencies (root, client, server)
npm run install-all
```

### 3. Environment Setup

Create `.env` in `server/` (or copy from `.env.example`):

```bash
cp .env.example server/.env
```

Edit `server/.env`:
```ini
PORT=5000
MONGODB_URI=mongodb://localhost:27017/wallet-wars
SOLANA_RPC_URL=https://api.mainnet-beta.solana.com
CLIENT_URL=http://localhost:5173
NODE_ENV=development
```

### 4. Seed Starter Warriors (Optional)

Populate the arena with starter crypto gladiators for immediate matchmaking:

```bash
npm run seed
```

### 5. Launch Development Server

Run both the backend API and frontend Vite server concurrently:

```bash
npm run dev
```

- 🎮 **Frontend**: `http://localhost:5173`
- ⚙️ **Backend API**: `http://localhost:5000`
- 🩺 **Health Check**: `http://localhost:5000/api/health`

## 🎮 Game Modes

1. **Quick Battle**: Instant matchmaking against an evenly matched arena gladiator based on your power level.
2. **Target Wallet Battle**: Challenge any specific Solana address or friend's wallet directly into the arena.
3. **Daily Arena Gauntlet**: Complete daily thematic conditions (e.g. *Defeat a Whale with a Degen*) for bonus XP and badges.
4. **Spectate & Share**: View interactive combat logs, share battle outcomes, and download warrior combat identity cards.

## 📡 REST API Reference

| Method | Endpoint | Description |
|:---|:---|:---|
| `POST` | `/api/wallet/analyze` | Fetch Solana telemetry & synthesize warrior specs |
| `POST` | `/api/warriors` | Register or update wallet warrior profile |
| `GET` | `/api/warriors/:address` | Fetch a specific warrior by wallet address |
| `GET` | `/api/warriors/opponents/find` | Find balanced arena opponents by ELO/level |
| `POST` | `/api/battles` | Execute a battle round simulation between 2 warriors |
| `GET` | `/api/battles/:id` | Fetch verified battle history and combat log |
| `GET` | `/api/leaderboard` | Retrieve global leaderboard rankings |
| `GET` | `/api/game/daily-challenges` | Get current daily active challenges |
